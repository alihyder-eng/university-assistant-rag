# University Assistant RAG

An AI-powered university assistant that uses RAG to answer questions from university documents.

## Features

* PDF document processing
* Semantic search
* ChromaDB vector database
* HuggingFace embeddings
* Source citations
* Streamlit chat interface
* Ollama, OpenAI & Gemini support

## Tech Stack

Python, LangChain, Streamlit, ChromaDB, HuggingFace, Ollama, PyPDF

## Setup

```bash
git clone https://github.com/alihyder-eng/university-assistant-rag.git
cd university-assistant-rag
pip install -r requirements.txt
streamlit run app.py
```
